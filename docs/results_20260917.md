# BiPulseFormer cross 결과 — 2026-09-17

현재 고정 프로토콜에서 PURE direct는 rPPG-Toolbox에 보고된 PhysFormer보다 두 target의 recording HR 지표가 수치상 좋다. PURE→UBFC-rPPG에서 MAE 1.088/RMSE 2.530 BPM, PURE→PHYS에서 4.901/9.007 BPM이다. 따라서 과거 프로토콜에서 관찰한 낮은 cross 성능을 현재 모델 전체에 대한 결론으로 사용하지 않는다.

이 문서는 `final_protocol_20260914` 결과만 집계한다. 이전 v1·journal·source-optimized 결과를 새 결과와 합치거나 삭제하지 않는다. [실행 코드·원본 결과 집계](../experiments/final_protocol_20260914/README.md), [고정 프로토콜](final_protocol_20260914.md)을 함께 제공한다.

모든 우리 결과는 seed42, best epoch2다. MAE/RMSE는 BPM, MAPE는 %, Pearson은 HR 상관계수다. 문헌은 video 단위 참고값이며, 아래 수치는 중심값이다.

출처: [rPPG-Toolbox, NeurIPS 2023, Table 7·8](https://proceedings.neurips.cc/paper_files/paper/2023/file/d7d0d548a6317407e02230f15ce75817-Paper-Datasets_and_Benchmarks.pdf#page=21), [FactorizePhys, arXiv v1, Table 2](https://arxiv.org/html/2411.01542v1#S4.T2). PhysFormer 원 논문의 해당 방향 측정값이 아니라 후속 저자들의 재현값이다. 두 출처를 평균하거나 더 유리한 문헌만 선택하지 않는다.

- Toolbox 대비 direct의 MAE/RMSE 참고 감소율: PURE→rPPG **24.4%/32.9%**, PURE→PHYS **18.9%/7.8%**.
- FactorizePhys의 PhysFormer PURE→rPPG 재현값보다는 direct의 MAE가 0.078 BPM, RMSE가 0.130 BPM 높다.
- Restored는 rPPG에서 Toolbox보다 네 HR 지표가 좋지만, PHYS에서는 MAE/MAPE가 소폭 낮고 RMSE/Pearson은 좋지 않다. 모든 후보를 함께 공개한다.

두 후보의 source validation recording RMSE는 epoch2부터 동률 0이었다. 최저 source RMSE → 이른 epoch → 후보 동률이면 direct라는 사전 규칙에 따라 direct가 주 결과로 선택됐다. Target 결과로 후보나 epoch를 바꾸지 않았다. Clip 최저 RMSE epoch와는 다른 선택이다.

## 남은 실험 — 문서 생성 시점

| 작업 | 상태 |
|---|---|
| PURE direct/restored 20epoch 학습 2건 | 완료, 모든 epoch 및 별도 best 저장 |
| 두 PURE 후보의 rPPG·PHYS test 4건 | 완료 |
| PHYS direct 학습 | 학습 HR이 고정 CE 구간 밖이어서 사전검사 부적격 |
| PHYS direct → PURE·rPPG | 선행 모델 부적격으로 실행 불가; 큐가 해당 행에 도달하기 전 pending 표시 가능 |
| PHYS restored 20epoch 학습 | 진행 중 |
| PHYS restored → UBFC-rPPG | 학습 후 대기 |
| PHYS restored → PURE | 같은 source best로 평가 대기 |

실질적으로 남은 작업은 PHYS restored 학습 완료와 test 2건이다. PHYS-source cross 방향에 해당하는 PhysFormer 수치는 위 두 문헌에서 확인되지 않았으므로 다른 방향의 숫자로 채우지 않는다. 이 문서는 정적인 보고이며 최신 진행률은 로컬 실행 상태에 기록된다.

## 논문에서 주장할 수 있는 범위

현재 근거는 **명시한 프로토콜에서 얻은 BiPulseFormer의 cross 결과가 Toolbox의 PhysFormer 재현 보고값보다 낮은 HR 오차를 보였다**는 것이다. 학습 source 분할, 20epoch 예산, loss, 입력 crop/resize·정규화, stride80 overlap은 명시적 방법 차이다. 평가 GT·구간·36–198 BPM scorer는 우리 후보 사이에서 공통이지만 이것만으로 2023 논문 환경 전체와 동일해지는 것은 아니다. UBFC subject37은 실제 decoded1170 중 완성1120frames/7clips를 사용한다.

현재 프로토콜의 PhysFormer 직접 재실행과 라우팅 제거 ablation은 없다. 따라서 모델 구조만의 우위, 라우팅의 인과적 기여, 통계적 유의성 또는 SOTA를 확정하지 않는다. 이미 여러 차례 관찰한 target이므로 완전히 새로운 blind test로 표현하지 않는다. 과거의 낮은 cross 수치와 실패는 당시 프로토콜의 이력으로 보존하고 현재 결론과 분리한다.
