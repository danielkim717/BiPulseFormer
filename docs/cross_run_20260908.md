# Cross 실험 실행 기록 — 2026-09-08

> Historical experiment notes. For the current method and results, start with the [repository overview](../README.md) and [documentation map](README.md). These notes are not the current execution plan.

## 코드 흐름 재검증

- 기존 12개 테스트와 추가 2개 테스트 모두 통과했다.
- 같은 가중치에서 모든 16개 영역을 선택한 BiPulseFormer(sparse path)의 최종 파형 출력이 PhysFormer full attention 출력과 수치 허용오차 내에서 일치한다.
- 주파수 loss의 미분 가능한 PPG 복원과 평가의 NumPy/SciPy 복원 연산이 일치한다.
- 기존 STE/sparse 일치, routing gradient, timestamp 정렬, train→validation→test 순서 테스트도 통과했다.
- PURE 10명/59영상/749클립, UBFC 42명/42영상/470클립에서 프레임 파일 존재와 HR target 생성 검사를 통과했다. 손상 여부에 대한 모든 영상 프레임 디코딩 검사는 아니며 학습 로더가 실제 읽기 실패를 별도로 검사한다.

## 실행

`results/cross_v1_20260908/`에 코드·설정 사본을 고정하고 다음 12개 실험을 순차 실행한다.

- 방향: PURE→UBFC-rPPG, UBFC-rPPG→PURE.
- 모델: BiPulseFormer, PhysFormer.
- 학습 seed: 42, 43, 44.
- 각 20epoch, 공통 protocol_v1.json, source validation 선택 후 target 전체 평가.
- 실행 순서: seed 42의 양방향·두 모델 비교부터 완료한 뒤 seed 43/44 진행.
- CPU threads=2, DataLoader workers=2. GPU 메모리 충돌을 피하기 위해 GPU 학습은 하나씩 실행.

## 진행과 결과 파일

- `results/cross_v1_20260908/status.json`: 전체 작업 상태와 PID.
- 각 실험의 `progress.json`: epoch/batch/단계.
- 각 실험의 `summary.json`: 완료된 최종 test 결과.
- `results/cross_v1_20260908/comparison.md`: 완료된 결과부터 추가되는 baseline 비교표.
- 방향별 aggregate JSON: 모델별 세 seed가 모두 완료되면 생성.

최종 성능 수치는 아직 측정 전이며, 기존 프로토콜 결과를 새 실험의 결과로 사용하지 않는다. CUDA MaxPool3d backward는 비결정적이므로 같은 seed의 bitwise 재현은 보장하지 않는다.
