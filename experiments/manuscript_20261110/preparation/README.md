# Dataset preparation helpers

These scripts contain the COHFACE inventory/timebase audits and UBFC-to-PURE cache/prelaunch preparation used with the workers. Configure their workspace/data paths before using them on another machine. They are project-layout scripts, not portable one-command launchers. Dataset loading/transforms live in the common implementation and task-specific worker folders. Read `../TRAINING.md` before creating caches or launching training.
